# nix-forge

NixOS, nix-darwin, Home Manager, and independently maintained Nix packages.

- [nix-conf](https://github.com/nix-forge/nix-conf) configures desktop and macOS systems.
- [nixpkgs-personal](https://github.com/nix-forge/nixpkgs-personal) provides the package collection and direct flake interface. NUR support is being prepared.
- [nix-config-framework](https://github.com/nix-forge/nix-config-framework) supplies configuration discovery.
- [nix-seal](https://github.com/nix-forge/nix-seal) manages secrets.
- [vpn-confinement](https://github.com/nix-forge/vpn-confinement) confines selected services to WireGuard.
- [ci](https://github.com/nix-forge/ci) maintains shared workflows and repository automation.

Report issues in the repository that owns the package or feature.
