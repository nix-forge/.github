# nix-forge

NixOS, nix-darwin, Home Manager, and independently maintained Nix packages.

- [nix-conf](https://github.com/nix-forge/nix-conf) configures desktop and
  macOS systems. Its [public guide](https://nix-forge.github.io/nix-conf/)
  starts with a small reusable configuration.
- [nixpkgs-personal](https://github.com/nix-forge/nixpkgs-personal) provides
  the [package catalog](https://nix-forge.github.io/nixpkgs-personal/catalog/)
  and direct flake interface. NUR support is being prepared.
- [nix-config-framework](https://github.com/nix-forge/nix-config-framework)
  supplies configuration discovery and a
  [minimal consumer guide](https://nix-forge.github.io/nix-config-framework/getting-started/).
- [nix-seal](https://github.com/nix-forge/nix-seal) manages secrets. Start
  with its [setup and operator documentation](https://nix-forge.github.io/nix-seal/).
- [nix-homelab](https://github.com/nix-forge/nix-homelab) provides
  [composable NixOS media services](https://nix-forge.github.io/nix-homelab/).
- [vpn-confinement](https://github.com/nix-forge/vpn-confinement) confines
  selected services to WireGuard.
- [ci](https://github.com/nix-forge/ci) maintains
  [shared workflow contracts](https://nix-forge.github.io/ci/) and repository
  automation.

Report issues in the repository that owns the package or feature.
