# Code of conduct

The nix-forge projects follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html), version 2.1.

We expect participants to be respectful, direct, and constructive. Harassment,
discrimination, threats, personal attacks, sexualized conduct, trolling, and
publication of another person's private information are not acceptable.

## Reporting concerns

Please report conduct concerns privately to the repository maintainers through
GitHub rather than opening a public issue. Include the project, relevant links,
dates, and any context that is safe to share. Do not include secrets or
unnecessary personal data. Maintainers will review reports promptly and keep
them confidential to the extent practical.
